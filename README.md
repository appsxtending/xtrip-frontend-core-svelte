# XTrip Svelte foundation

Private standalone @xtrip/ui-svelte foundation, version 0.1.0. F0.1 delivers an adapter-node SSR workbench, a safe presentation export seam, per-request locale/theme policy and architecture tests. Product applications, reusable component families, design-token and i18n packages, generated API client and sessions follow in later approved tasks.

Use Node 24.18.0. Run `npm ci`, then `npm run dev` and open http://127.0.0.1:5173. Production: set XTRIP_WEB_ORIGIN to the canonical external origin before `npm run build`; set HOST and PORT at runtime, then `npm start`. The default build origin is http://127.0.0.1:4173 for local production tests. SvelteKit 3 uses build-time paths.origin instead of the removed runtime ORIGIN variable. Development derives the Vite request origin. Never trust forwarded origins without a trusted reverse proxy. The workbench is non-indexable and not an authenticated product application; do not place tenant data in it.

`npm run verify` runs lint/format, strict typecheck, unit/component/architecture tests, production SSR and library build, and Chromium Playwright journeys. Install the browser with `npx playwright install chromium`. Evidence and visual fixtures are written to ignored test-results and playwright-report directories. Initial screenshots are checked for deterministic rendering and manually reviewed; no historical visual regression baseline is claimed. F0.1 local budgets: decoded route JavaScript under 200 kB and CSS under 80 kB. Rendering budgets additionally check local TTFB < 2 s, LCP < 2.5 s, CLS < 0.1 and observed interaction event duration < 200 ms. These are laboratory checks, not field INP/Core Web Vitals or release certification.

The 34 approved source/configuration paths are catalogued in contracts; generated build output is ignored. The library exports presentation locale/theme types and localized foundation copy only, with no server policy export. The SSR demo uses an allowlisted appearance form; it changes the URL and does not persist user data. Origin and Fetch-Metadata checks, SvelteKit CSRF, nonce CSP, Trusted Types and private response headers protect the host boundary.

The real backend is at http://localhost:4000. F0.1 does not make business API calls; F0.2 establishes the pinned generated client and real-API journeys. API health, readiness and public-contract alignment are recorded separately in the requirements checkpoint. Git origin is https://github.com/appsxtending/xtrip-frontend-core-svelte.git (supplied by the owner). Package publication remains disabled.
